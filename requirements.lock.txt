# requirements.txt 用 `>=` 声明「兼容范围」，适合表达意图，但不锁定具体版本：
# 同一份文件在不同时间安装会得到不同结果。本项目实测到的漂移非常激进：
#
#   openai>=1.50   声明写 1.50，本地实装 3.14.1，而 pip 当前解析出 3.16.2
#   langgraph>=0.2.60          本地实装 1.2.11（跨大版本）
#   langgraph-checkpoint-*     本地实装 3.1.x（声明下限 2.x）
#
# 跨大版本的 langgraph / openai 一旦变更 checkpoint 序列化格式或 tool_call 结构，
# 「断点恢复」「工具调用」两处核心能力会静默失效。
#
# 用法：
#   pip install -r requirements.lock.txt     # 复现已知可用的组合（推荐 CI 用）
#   pip install -r requirements.txt          # 允许在声明范围内升级（本地开发）
#
# 生成方式：pip list --format=freeze（本机 conda env agent-runtime / Python 3.11.16），
# 即「205 条离线用例 + 四项指标全部实测通过」的那套版本。
